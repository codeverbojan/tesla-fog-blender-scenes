# Why Tesla’s Screen Looks So Clear in Thick Fog

Editable Blender scenes from the Fetching Westie film. Open any file in Blender 4.1.1. To explore the animation, switch to the active camera with Numpad 0 and scrub the timeline. [Watch the film](https://www.youtube.com/watch?v=iJBMr-a1S0Q)

| Scene | Open in Blender |
| --- | --- |
| Dashboard reconstruction | [reality-screen.blend](reality-screen.blend) |
| Night drive and brake lights | [night-cabin-v3.blend](night-cabin-v3.blend) |
| Camera shutters and film transport | [exposure-transport.blend](exposure-transport.blend) |
| AI4 chip close-ups | [ai4-macros-v3.blend](ai4-macros-v3.blend) |
| Phone and exploded lens | [phone-optics.blend](phone-optics.blend) |
| Roadside camera positions | [street-optics.blend](street-optics.blend) |
| Steering and display paths | [two-outputs.blend](two-outputs.blend) |
| Truck and hidden motorcycle experiment | [trailer-test.blend](trailer-test.blend) |
| Parking-space selection | [parking-intent.blend](parking-intent.blend) |
| Animated layers from the closing shot | [recorded-layers.blend](recorded-layers.blend) |

The phone screen and four surfaces in the closing shot use flat colors. To use your own image, select the surface, open its material in the Shader Editor and choose **Open** on its Image Texture node.
